ENEC — Admin du vrai ancien site
Modifie accueil, domaines, mission, vision, équipe, images — puis télécharge le site mis à jour.

Comment ça marche ?

1. Tu modifies ici.
2. Tu cliques sur 💾 Enregistrer dans Supabase (sauvegarde).
3. Tu cliques sur ⬇️ Télécharger le site mis à jour (index.html).
4. Tu mets ce nouveau index.html sur GitHub → ton ancien site affiche les nouvelles infos.

Les images : tu choisis JPG/PNG → converties automatiquement en WebP → elles remplacent l'image dans le site.
